## Installation

> **Step 1** — Download `Dimraeth_Trainer_v1.0` using the button above and extract the archive to any folder

> **Step 2** — Run `Dimraeth_Trainer_Installer` to launch the installer

> **Step 3** — Choose a destination folder (default: `C:\Program Files\DimraethTrainer`) and click **Install**

> **Step 4** — Once installation is complete, navigate to the chosen folder, right-click `Dimraeth_Trainer`

> **Step 5** — Launch **Dimraeth** via Steam

> **Step 6** — Press `INSERT` in-game to open the trainer menu

> ⚠️ **Note:** If the trainer doesn't appear, make sure you run it as administrator and the game is in windowed or borderless mode.
